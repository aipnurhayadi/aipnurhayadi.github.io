# Project Rules

## Repository

This repository is:

aipnurhayadi.github.io

It is the production website repository.

## Source

The primary design source is:

../aipnurhayadi.github.io.lovable-design

The source repository must be treated as read-only.

## Architecture

The target website must use:

- Jekyll
- Liquid
- HTML
- CSS
- JavaScript

Do not introduce React into the final website.

## Design

The Lovable project is the visual source of truth.

Do not redesign the UI unless explicitly requested.

## Branding

The final website must NOT use Lovable branding.

Never use:

- Lovable favicon
- Lovable default favicon
- Lovable logo as favicon
- Lovable branding metadata
- Lovable-specific title or description
- Lovable-specific Open Graph images
- Lovable-specific manifest or PWA branding

The favicon must be replaced with a project-specific favicon.

If the source repository contains a Lovable-generated favicon, do not copy it.

If no custom favicon is provided, create or configure a neutral project-specific favicon placeholder rather than using the Lovable default.

Verify that the final HTML references the intended favicon.

## Code Quality

Prefer:

- reusable components
- semantic HTML
- accessible markup
- minimal JavaScript
- maintainable CSS

Avoid unnecessary complexity.
